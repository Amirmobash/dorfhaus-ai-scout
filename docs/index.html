🏡 DorfHaus AI Scout

Ein Open-Source-Werkzeug zur transparenten Bewertung von Wohnhäusern in Nordrhein-Westfalen – Region zwischen Köln und Düsseldorf.

Immobilien besser vergleichen

Kaufnebenkosten, Finanzierungsraten und Hinweise auf mögliche Sanierungsrisiken übersichtlich bewerten. CSV-Angebote lokal importieren und Ergebnisse nachvollziehbar vergleichen.

Derzeit MVP mit CSV-Import. Keine automatisierte Live-Suche und keine Immobilienangebote auf dieser Seite.

Quellcode und Installationsanleitung auf GitHub
