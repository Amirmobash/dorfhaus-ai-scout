# Auffindbarkeit bei Suchmaschinen

Die Projektseite enthält einen deutschen Titel, eine Beschreibung, eine kanonische URL und semantische HTML-Überschriften.

## Veröffentlichung
In GitHub unter **Settings → Pages** die Quelle **Deploy from a branch**, Branch **main**, Ordner **/docs** auswählen. Erst danach ist die Projektseite unter https://amirmobash.github.io/dorfhaus-ai-scout/ erreichbar. Die Indexierung durch Google ist nicht garantiert.

Die Website enthält keine privaten Angaben und keine erfundenen Immobilienangebote.
